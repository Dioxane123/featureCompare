# 视觉大模型特征性能比较 (Visual Foundation Models Feature Comparison)

本项目主要通过在公开数据集上进行图像内容检索任务，来评估和比较不同视觉大模型提取的特征性能。实验目前主要聚焦于对比 **DINOv3** 和 **CLIP** 在不同参数规模下的检索准确率。

## 实验目的

测试并验证主流视觉基础模型（如 DINOv3 和 CLIP）在图像相似度匹配和检索任务中的能力差异。通过比对不同输出模式（Feature 模式与 Embedding 模式）以及不同模型参数量对最终 Top-K 检索结果的影响，为后续的特征融合或传统方法结合提供基线数据。

## 数据集

实验使用了以下两个主要数据集进行测试：

* **SMVS (Stanford Mobile Visual Search)**: 包含 business_cards、cd_covers、dvd_covers、landmarks、museum_paintings、print、video_frames 等多个子类别。
* **DISC21 (Image Similarity Challenge 2021)**: 使用了 Kaggle 上的自用子集，其中 Queries 由 500 张有真值的图片组成，References 库包含全量 50000 张图片。

## 评估模型与特征提取机制

本项目评估了多种不同参数规模的模型，并对其输出特征进行了标准化处理：

### DINOv3

利用 `timm` 库提供的 DINOv3 模型。测试了以下版本：

* small (21M) / small+ (29M) / base (86M) / large (300M) / huge+ (840M)

**特征提取模式**：

1. **Embedding 模式**: 对每张图片输出一个 768 维的张量，并进行 L2 正则化。
2. **Feature 模式**: 输出三个 `[B, 768, 16, 16]` 的张量（对应不同层数特征图）。处理时，对特征图进行 16x16 平均池化，随后进行 L2 正则化提取可用特征向量。

### CLIP

测试了以下版本：

* xsmall (8M) / medium (38M) / base (86M) / large (304M)

## 核心实验结论

通过多次迭代和测试，得出了以下初步结论：

1. **特征层级的影响**: 随着网络层数变深，基于 Feature 图提取的特征效果越好，但通常**直接使用 Embedding 得到的特征表现最佳**。
2. **模型规模的影响**: 通常情况下，模型参数量越大，检索效果越好。但在 SMVS 数据集的全面测试中，DINOv3 的 huge+(840M) 模型出现了性能反常下降的情况。
3. **DINOv3 vs CLIP**:
    * **CLIP** 在特定文本相关或高辨识度物体类别（如名片 business_cards、DVD/CD 封面 dvd_covers）上展现出极高的准确率（CLIP-large 的 Top-3 准确率可达 90% 以上）。
    * **DINOv3** 在地标（landmarks）和视频帧（video_frames）等类别上相对更具优势。
